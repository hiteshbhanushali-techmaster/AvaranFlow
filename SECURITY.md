# Security Policy

## Supported Versions

| Version | Supported | Notes |
|---|---|---|
| `1.0.x` | :white_check_mark: | Current active release branch |
| `< 1.0.0` | :x: | Prerelease and historical iterations |

---

## Reporting a Vulnerability

If you discover a security vulnerability, denial-of-service issue, or uncontained exception leak in AvaranFlow:

1. **Do NOT disclose the issue publicly** on GitHub Issues, Discussions, or social media.
2. Email a detailed vulnerability report privately to the maintainer:
   - **Contact:** [hiteshbhanushali.techmaster@gmail.com](mailto:hiteshbhanushali.techmaster@gmail.com)
3. Please include:
   - Component affected (`AvaranFlow.Core`, `AvaranFlow.Alerting.Core`, or specific sink).
   - Target framework (`netstandard2.0`, `net461`, or `net8.0`).
   - A minimal reproduction code example.
   - Any remediation or patch if known.

---

## Timeline

- **Initial Response:** Within 48 hours.
- **Triage & Reproduction:** Within 5 business days.
- **Fix & Advisory:** A patch will be tested across all supported frameworks before releasing a security patch.
