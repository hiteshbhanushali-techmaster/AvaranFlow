Architectural Highlights

1.24 µs

CAS Storm Deduplication

Repeating exceptions update atomic counters in 1.24 microseconds with 0 B allocations.

Bounded Queue

Memory Protection

Never crash with OutOfMemory. Configurable DropOldest, DropNewest, and BlockWithTimeout policies.

Policy Alerting

Headless Engine

Ascending-order rules, dynamic severity resolution, sliding-window suppression, and escalation.

Zero Crash

Failure Containment

Sink errors and rule evaluation exceptions are fully contained and never escape into host threads.

Quick Start Installation

# Install Core exception engine:
dotnet add package AvaranFlow.Core --version 1.0.0

# Optional policy-driven alerting engine:
dotnet add package AvaranFlow.Alerting.Core --version 1.0.0

Basic Usage

using ExceptionMaster.Core;

// Configure buffering and sinks at startup
var options = ExceptionMasterOptions.CreateDefault();
options.EnableAsyncDispatch = true;
options.BufferCapacity = 5000;
ExceptionMaster.Core.ExceptionMaster.Configure(options);

// Capture anywhere safely:
try
{
    ExecuteCriticalTask();
}
catch (Exception ex)
{
    ExceptionMaster.Core.ExceptionMaster.Log(ex);
}
