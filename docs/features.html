AvaranFlow Features

1. In-Memory Atomic CAS Storm Deduplication

Normalizes exception messages (strips GUIDs, hex IDs, dynamic parameters) and updates in-memory aggregate records via lock-free atomic CAS. Producer threads return in ~1.2 µs without blocking on disk or network writes.

2. Bounded Asynchronous Dispatch Pipeline

Configurable in-memory ring buffer prevents OutOfMemory crashes under massive exception storms. Supports DropOldest, DropNewest, and BlockWithTimeout policies.

3. Policy-Driven Rule Evaluation Engine

Deterministic ascending-order rule evaluation with dynamic severity resolution (Warning, Error, Critical). Sinks and notification destinations receive clean, sanitized AlertEnvelope boundaries.

4. Rule-Scoped Suppression & Escalation

Enforce cooldown durations, sliding time windows, and occurrence rate-limits per rule. Breached thresholds elevate alert severity and dispatch escalation notifications.

5. Multi-Sink Fan-Out & Fallback Cascades

Deliver alerts simultaneously to multiple destinations (Console, File, SQL Server, NLog) or fallback cascades that automatically recover if a primary storage sink fails.
